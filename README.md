# relaxing_tiles
# Учебная практика
Игра реализована с помощью игрового двигателя Godot Engine в рамках учебной практики в Санкт-Петербургском Государственном Университете Аэрокосмического Приборостроения (ГУАП) студентом группы 4526 1 курса направление 09.03.02 (информационные системы и технологии) Васильевой Марией.
# Суть игры
Классический тетрис с расслабляющей музыкой и графикой.
# Управление
С помощью кнопок A, S, D, Q, E, пробел, Escape можно подвинуть фиугру влево, вниз, вправо, повернуть влево, повернуть вправо, резко опустить, нажать на паузу соответственно.
